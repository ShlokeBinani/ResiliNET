**ResiliNet** is a decentralized 6G network orchestration simulator. It demonstrates how blockchain-based smart contracts and predictive models can dynamically allocate bandwidth, execute "Social Slicing" during high-load events, and ensure 99.999% uptime for critical infrastructure.

## 🚀 Features

* **Operator Control Terminal:** Manually inject residential and critical infrastructure traffic to observe network strain.
* **Autonomous Sentinel (AI Guardian):** Real-time monitoring mode that uses predictive physics curves to automatically trigger the Social Slice Protocol when congestion exceeds 85%.
* **Digital Twin Visualization:** 3D interactive mapping of the network topology (currently modeled on the VIT Vellore campus) using `pydeck`.
* **DeFi Liquidity Engine:** Simulated staking and reward mechanisms for node operators participating in the network.

## 🛠️ Tech Stack

* **Frontend & Framework:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Visualizations:** Plotly, PyDeck (3D Spatial Data)
* **Time & Scheduling:** Datetime, PyTZ
